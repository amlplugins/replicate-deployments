# @amlplugins/replicate-deployments

Native `replicate` SDK re-exported under the `@amlplugins` namespace.

> Replicate Deployments — create dedicated model endpoints with custom hardware, autoscaling, queue config.

## Install

```bash
npm install @amlplugins/replicate-deployments
```

## Use

```ts
import { /* named exports from replicate */ } from "@amlplugins/replicate-deployments";
// or
import sdk from "@amlplugins/replicate-deployments";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
